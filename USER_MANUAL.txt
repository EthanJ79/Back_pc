본 매뉴얼은 PGuard PC 활동 모니터링 및 생산성 분석 시스템의 설치, 운영 및 사용 방법을 
기술합니다. PGuard는 사내 직원들의 업무용 소프트웨어 사용율 및 비업무용 사이트(유튜브, 웹툰, 
쇼핑 등) 체류 기록을 안전하게 수집하여, 실시간 시각화 대시보드를 제공하는 솔루션입니다.

최근 고도화를 통해 [관리자 대시보드 권한 인증], [회사 코드 연동 필터링], [에이전트 최초 
설정 GUI 팝업], [직원별 통계 엑셀 다운로드], [macOS 원터치 더블클릭 인스톨러], [서버 무중단 배포]

1. 시스템 소개 및 보안 작동 메커니즘
================================================================================
PGuard 시스템은 크게 [백엔드 서버 및 관리 웹 대시보드]와 [PC 백그라운드 에이전트]로 구성됩니다.

* 보안 강화 패킷 검증 (회사 코드 연동)
  - 백엔드 서버에 설정된 '회사 코드(Company Code)'와 에이전트 패킷의 회사 코드가 일치할 때만 
    활동 데이터가 수집/적재됩니다.
  - 회사 코드가 불일치할 경우 에이전트에는 403 Forbidden 응답이 반환되며, 에이전트는 즉시 
    로컬 설정을 파기하고 가동을 정지하여 비인가 연동을 원천 차단합니다.

* 관리자 대시보드 인증 (Session Protection)
  - 대시보드의 실시간 통계, 상세 피드 로그, 데이터베이스 삭제, 회사 설정 API는 관리자 인증 
    토큰(Authorization: Bearer <token>)을 요구합니다.
  - 비인가 접근 시 미려한 슬레이트 다크 테마의 전면 로그인 오버레이 창이 표시되어 시스템 노출을 
    방지합니다.

2. 백엔드 API 서버 및 대시보드 설치/구동 방법
================================================================================
백엔드는 Node.js Express 및 SQLite3 기반으로 작동하며, 대시보드 웹 리소스(HTML/JS)를 직접 서빙합니다.

1. 사전 요구사항:
   - Node.js (버전 16 이상 추천)가 설치되어 있어야 합니다.

2. 의존성 패키지 설치:
   - 터미널을 열고 'server' 디렉토리로 이동한 뒤 아래 명령어를 실행합니다.
     $ cd d:/project/Back_PC/server
     $ npm install
	or
     $npm install --no-fund --save typescript @types/node @types/react @types/react-dom @types/jest

3. 초기 시드 데이터 적재 (선택 사항):
   - 임의의 직원 활동 데이터 및 차트 테스트용 목업 데이터를 생성하려면 시드 스크립트를 실행합니다.
     $ node seed.js

4. API 서버 및 대시보드 통합 실행:
   - 아래 명령어를 통해 포트 3000번으로 서버를 백그라운드 구동합니다.
     $ npm run dev  (또는 node server.js)
   - 실행 성공 시 터미널에 아래와 같은 안내가 출력됩니다.
     ==================================================
      직원 활동 모니터링 백엔드가 활성화되었습니다.
      포트: http://localhost:3000
     ==================================================

5. 기본 관리자 계정 정보:
   * 통합관리자 (Super Admin) 계정 정보:
     - 회사 연동 코드: auton
     - ID: admin
     - 비밀번호: pguard1234
   * 기본 등록 회사 (Company Admin) 계정 정보:
     - 회사 연동 코드: PGUARD1234
     - ID: admin
     - 비밀번호: pguard1234

3. PC 모니터링 에이전트(Agent) 초기 연동 설정 (GUI)
================================================================================
PC 활동을 수집하는 에이전트는 Python 3 환경에서 작성되었으며, 최초 실행 시 GUI 화면을 통해 
사원 정보를 입력받아 영구 저장합니다.

1. 에이전트 필수 의존 라이브러리 설치:
   - 'agent' 디렉토리의 requirements.txt를 참고하여 패키지를 사전 설치합니다.
     $ pip install -r requirements.txt
   - 주요 필요 모듈: requests, psutil, pywin32(Windows 전용), pyobjc(macOS 전용)

2. 최초 가동 및 설정 파일(config.json) 생성:
   - 에이전트를 처음 실행할 때 로컬에 'config.json'이 없거나 비어 있는 경우, 슬레이트 
     블랙 디자인 테마의 Tkinter GUI 'PGuard 연동 설정' 창이 즉시 팝업됩니다.
     $ python agent.py
   - 입력 필요 항목:
     * 회사 연동 코드 (Company Code) * : 관리자 대시보드 설정에 등록된 회사 코드 (예: PGUARD1234)
     * 사원 번호 (Employee ID) * : 직원의 고유 사번 (예: EMP2026001)
     * 사원 이름 (Employee Name) * : 직원의 이름 (예: 홍길동)
   - 필수값을 모두 채우고 [설정 저장 및 에이전트 시작] 버튼을 누르면 연동 파일이 생성되며, 
     에이전트는 조용히 백그라운드 모니터링 데몬 모드로 자동 전환됩니다.

3. 검증 차단 시나리오:
   - 서버의 회사 코드와 맞지 않는 임의의 코드를 입력하고 저장하여 활동 신호 전송 시, 백엔드로부터 
     '403' 차단 에러를 통보받습니다.
   - 이때 직원의 PC 화면에는 "회사 코드 불일치" 알림 경고창이 팝업되며, 로컬에 저장되었던 
     config.json 설정 파일은 자동으로 파기되고 에이전트는 안전하게 강제 종료됩니다.

4. 에이전트 OS별 자동 시작(Autostart) 설정 및 수동 해제 방법
================================================================================
PGuard 에이전트는 직원이 PC를 켜고 부팅하는 즉시 누락 없이 동작할 수 있도록 자동 시작 백그라운드 
서비스 등록 기능을 내장하고 있습니다.

1. Windows 환경 자동 등록 메커니즘
   - 에이전트 실행 시 Windows Registry의 아래 경로에 자동 등록됩니다.
     * 경로: HKCU\Software\Microsoft\Windows\CurrentVersion\Run
     * 키 명칭: PGuardAgent
   - 등록 수동 해제 방법:
     - 윈도우 검색창에 '작업 관리자' 입력 -> '시작 앱' 탭 선택 -> 'PGuardAgent' 찾아서 [사용 안 함] 클릭.
     - 혹은 레지스트리 편집기(regedit)를 실행하여 위 경로의 'PGuardAgent' 문자열 값을 삭제합니다.

2. macOS 환경 자동 등록 메커니즘
   - 에이전트 실행 시 macOS 고유 데몬 관리자인 LaunchAgent에 plist 설정 파일이 자동으로 쓰여집니다.
     * 파일 경로: ~/Library/LaunchAgents/com.pguard.agent.plist
   - 등록 수동 해제 방법:
     - 터미널을 열고 아래 명령어를 수행하여 등록을 정지 및 해제합니다.
       $ launchctl unload ~/Library/LaunchAgents/com.pguard.agent.plist
       $ rm ~/Library/LaunchAgents/com.pguard.agent.plist

5. 관리자 대시보드 조작 및 통계 Excel 내보내기
================================================================================
웹 브라우저를 통해 http://localhost:3000 에 접속하여 전체 대시보드를 통합 통제할 수 있습니다.

1. 로그인 수행:
   - 화면 중앙에 풀스크린 유리 질감(Glassmorphism)의 로그인 모달이 팝업됩니다.
   - [회사 코드], [관리자 아이디], [비밀번호]를 각각 입력하여 로그인합니다.
   - **통합관리자(Super Admin) 로그인**:
     * 회사 코드: auton
     * 아이디: admin
     * 비밀번호: pguard1234
     (Super Admin 로그인 시, 대시보드 상단에 [SUPER ADMIN] 배지가 표시되며 "회사 관리" 메뉴가 활성화됩니다.)
   - **회사 관리자(Company Admin) 로그인**:
     * 회사 코드: PGUARD1234 (또는 새로 등록한 개별 회사 코드)
     * 아이디: admin (또는 새로 생성한 회사 관리자 ID)
     * 비밀번호: pguard1234
     (Company Admin 로그인 시, [COMPANY: 회사코드] 배지가 표시되며 자사 소속 에이전트 정보만 완벽히 격리되어 조회됩니다.)
   - 대시보드는 한국어(ko), 영어(en), 태국어(th), 라오어(lo) 4개 국어 번역을 완벽 지원합니다. 우측 상단의 국기 셀렉터를 클릭하여 실시간으로 언어를 변경할 수 있습니다.

2. 통합관리자의 회사 관리 및 회사 관리자 생성 (Super Admin 전용):
   - 통합관리자(`auton`)로 로그인하면 사이드바 메뉴에 "회사 관리" 메뉴가 활성화됩니다.
   - **회사 등록/수정/삭제**: 중복되지 않는 고유 회사 코드를 등록하거나, 기존 등록된 회사의 이름을 수정/삭제할 수 있습니다. 회사를 영구 삭제할 시 해당 회사의 활동 기록, 등록 직원, 그리고 연결된 모든 회사 관리자 계정이 트랜잭션을 통해 일괄 Cascade 안전 소거됩니다.
   - **회사 관리자 계정 생성**: 등록된 회사 중 하나를 선택하고 새로운 관리자 ID와 비밀번호를 기입하여 회사별로 독립된 관리자 계정을 직접 발급할 수 있습니다.

3. 실시간 모니터링 및 격리 조회:
   - 전체 모니터링 사원 수, 실시간 접속 직원(최근 10분 내 신호 송신자), 오늘 전체 직원의 누적 비업무 체류 시간, 평균 업무 집중도(Work / Total Work) KPI 카드가 갱신됩니다.
   - 일반 회사 관리자는 자사 소속 에이전트의 데이터만 접근 및 조회 가능합니다.
   - 하단 '활동 감지 상세 피드'에서 우측 상단의 [비업무 경고만 보기] 체크박스를 활성화하면 업무와 무관한 사이트 검출 내역만 단독 정렬 및 필터링할 수 있습니다.

4. 📊 직원별 활동 통계 엑셀 다운로드 (Excel Export):
   본 대시보드는 SheetJS 엔진을 내장하여 별도의 서버 연동 부하 없이 즉시 프론트엔드 자체적으로 안전하고 신속하게 엑셀을 내려받을 수 있습니다.
   
   - **전체 요약 Excel 다운로드**:
     * 위치: [직원 활동 현황] 탭 좌측 '관리 사원 세부 현황' 테이블 상단 우측 [전체 요약 Excel] 버튼.
     * 기능: 관리 권한 내에 있는 모든 사원의 사번, 사원명, 소속 회사(Super Admin의 경우), 마지막 활동 통신 시각, 그리고 현재 실시간 접속 여부(온라인/자리비움) 데이터 일괄을 깔끔한 단일 행렬 시트로 정렬하여 내려받습니다.
     * 파일명 양식: `PGuard_전체직원현황_[YYYY-MM-DD].xlsx`
   
   - **이 직원 통계 Excel 다운로드**:
     * 위치: [직원 활동 현황] 탭 우측 '사원별 활동 통계 분석' 패널의 직원명 상단 우측 [이 직원 통계 Excel] 버튼.
     * 기능: 선택된 특정 직원의 기본 인적정보부터 오늘 자 업무 집중도 점수, 근무 시간 배분(업무, 비업무, 자리비움 각각의 시/분 환산), 최다 사용 소프트웨어 TOP 5 리스트, 최다 체류 비업무 위반 도메인 TOP 5 및 누적 방문 횟수를 정리한 고품격 그리드 구조의 보고서형 단일 시트를 생성하여 내려받습니다.
     * 파일명 양식: `PGuard_직원상세통계_[사원명]_[YYYY-MM-DD].xlsx`

5. 비밀번호 변경 및 로그아웃 (대시보드 설정 탭 & 사이드바):
   - **로그아웃**: 사이드바 하단의 [로그아웃] 버튼을 클릭하면 확인 팝업창이 뜨며, 승인 시 서버 세션이 즉시 무효화되고 브라우저의 저장 토큰이 완벽하게 삭제되어 안전하게 로그인 화면으로 복귀합니다.
   - **비밀번호 변경**: [대시보드 설정] 메뉴의 '보안 및 회사 연동 설정' 판넬에서 새 비밀번호를 입력하고 저장하면 관리자 비밀번호가 SHA256 해시 데이터로 완전 갱신됩니다.

6. 데이터베이스 전체 초기화 (위험 구역):
   - 대시보드 설정 탭의 우측 하단에 [활동 데이터베이스 전체 초기화] 빨간색 버튼이 제공됩니다.
   - 회사 관리자로 로그인해 실행하면 자사 소속의 사원/활동 로그 데이터만 격리 초기화되며, 통합관리자로 로그인해 실행하면 데이터베이스 전체의 누적 로그가 일괄 청소됩니다.

6. macOS 전용 원터치 에이전트 인스톨러 (install_mac.command) 가이드
================================================================================
맥 OS를 사용하는 일반 직원들이 터미널 명령을 수행하지 않고 더블 클릭만으로 손쉽게 에이전트를 가동하고 
자동 백그라운드 등록을 마칠 수 있는 원터치 인스톨러 파일(`install_mac.command`)을 제공합니다.

1. 준비 사항:
   - 다운로드받은 PGuard Agent 폴더 내의 `install_mac.command` 스크립트 파일을 준비합니다.

2. 실행 절차 (원클릭 설치):
   ① `install_mac.command` 스크립트를 마우스 우클릭 -> 열기(또는 더블 클릭)하여 실행합니다.
   ② 자동으로 macOS Terminal이 실행되며 터미널 상에 진행률과 안내가 출력됩니다.
      - **자동 설치 메커니즘**:
        1) Python 3 설치 여부 및 pip 탑재 여부를 검출하여 누락 시 자동 셋업
        2) 필수 외부 의존 패키지(requests, psutil, pyobjc) 자동 설치 및 버전 업
        3) macOS Gatekeeper 격리 속성 우회 명령어(`xattr -d com.apple.quarantine`) 및 실행 권한 부여(`chmod +x`)를 원스톱으로 처리
        4) 로그인 시마다 에이전트가 백그라운드 기동하도록 사용자 계정 서비스(`~/Library/LaunchAgents/com.pguard.agent.plist`) 생성 및 로드(launchctl load) 기동 완료
        5) 최초 설정창 GUI를 화면에 안전하게 즉각 팝업하여 회사 코드 및 직원 정보 기입 지원
   ③ 최초 1회 회사 코드 입력 GUI가 켜지면 필요한 연동 항목(서버 URL, 회사 코드, 사번, 이름)을 입력하고 설정을 저장하면 연동과 함께 백그라운드로 즉시 조용히 전환됩니다.
   ④ 이후 Terminal 창을 닫아주시면 모든 설치 과정이 완전히 종료됩니다.

3. 에이전트 상태 모니터링 및 로그 확인:
   - 실시간 에이전트 동작 로그 확인: `agent/agent.log` 파일 분석
   - 표준 출력 및 표준 에러는 아래 파일로 분리되어 수집됩니다.
     * `$SCRIPT_DIR/agent_stdout.log`
     * `$SCRIPT_DIR/agent_stderr.log`

4. macOS 서비스 강제 정지 및 완전 삭제(Uninstall) 방법:
   - 맥 터미널을 열고 아래 명령어 두 줄을 복사하여 실행해 주시면 즉시 삭제됩니다.
     $ launchctl unload ~/Library/LaunchAgents/com.pguard.agent.plist
     $ rm ~/Library/LaunchAgents/com.pguard.agent.plist

7. macOS 전용 애플리케이션 (.app) 빌드 가이드
================================================================================
맥 환경에서 파이썬 터미널 명령을 매번 칠 필요 없이, 직원들이 더블 클릭만으로 GUI 설정창을 띄우고 
자동 기동할 수 있도록 macOS 고유 빌더가 마련되어 있습니다.

1. 사전 요구사항:
   - macOS 기기(MacBook, Mac mini 등) 환경이어야 합니다.
   - Python 3 및 pip가 준비되어 있어야 합니다.

2. 빌드 실행 방법:
   - 'agent' 폴더로 이동한 뒤 제공되는 'build_macos.py' 스크립트를 즉시 실행합니다.
     $ cd d:/project/Back_PC/agent
     $ python build_macos.py
   - 스크립트가 로컬 환경의 pyinstaller, pyobjc(AppKit/Quartz), requests, psutil 등을 자동 검출하여 
     누락 시 pip 설치까지 원터치로 연계 처리합니다.
   - 이후 빌드가 완료되면 'agent/dist/PGuardAgent.app' 디렉토리가 생성됩니다.

3. 게이트키퍼(Gatekeeper) 및 격리 속성 우회 명령어:
   - macOS 정책상 미인증 서명 애플리케이션을 더블 클릭할 경우 게이트키퍼 오류 경고가 뜨며 실행이 
     차단될 수 있습니다. 배포 전에 맥 터미널에서 아래 명령을 1회 실행해 주세요.
     $ sudo xattr -rd com.apple.quarantine ./dist/PGuardAgent.app
     $ chmod -R 755 ./dist/PGuardAgent.app

8. 실운영 서버(Production Server) PM2 무중단 상시 구동 및 배포 가이드
================================================================================
사내 내부망 서버(Intranet) 또는 클라우드 가상 컴퓨터(AWS EC2, Google Cloud, Windows Server 등)에 
PGuard 백엔드 API와 대시보드 시스템을 상시 무중단 형태로 기동하는 가이드를 기술합니다.

1. 서버 측 Node.js 및 SQLite3 세팅:
   - 프로덕션 서버에 Node.js(LTS 버전 18 이상 추천)를 공식 페이지를 통해 설치합니다.
   - PGuard 백엔드 서버 소스 코드를 서버의 특정 배포 폴더(예: `/var/www/pguard`)에 배치합니다.
   - 해당 폴더에서 의존 라이브러리를 프로덕션 모드로 설치합니다.
     $ npm install --production

2. PM2(Process Manager 2)를 활용한 백그라운드 무중단 상시 구동:
   터미널 세션이 끊기거나 프로그램에 예기치 못한 에러가 발생해도 서버를 자동으로 자가 재기동해 주는 
   PM2 프로세스 관리자 설치 및 기동법입니다.
   
   ① PM2 전역 설치:
      $ npm install -g pm2
   
   ② 서버 무중단 기동 시작:
      $ pm2 start server.js --name "pguard-server"
   
   ③ 서버 재부팅 시 자동 기동 및 상태 저장:
      $ pm2 save
      $ pm2 startup
      (리눅스 환경의 경우 pm2 startup 실행 시 출력되는 복사용 sudo 명령어를 그대로 터미널에 한 번 더 붙여넣어 실행해야 부팅 데몬으로 완전히 활성화됩니다.)
   
   ④ PM2 유용한 관리 명령어 모음:
      - 실시간 프로세스 구동 상태 모니터링: `$ pm2 list` 또는 `$ pm2 status`
      - 실시간 통합 로그 보기: `$ pm2 logs`
      - 특정 프로세스 재시작: `$ pm2 restart pguard-server`
      - 특정 프로세스 일시 중지: `$ pm2 stop pguard-server`

3. 네트워크 포트 방화벽 개방 및 인바운드 규칙 설정:
   에이전트 PC들이 인터넷이나 사내 내부망을 통해 원격지에 배포된 PGuard 서버에 정상 접속하여 수집 로그를 
   적재할 수 있도록 포트 및 방화벽 개방이 필요합니다.
   
   - **AWS EC2 (클라우드 환경)**:
     * AWS Management Console -> EC2 -> 인스턴스 -> 보안 그룹(Security Groups) 선택.
     * 인바운드 규칙 편집(Edit Inbound Rules) -> [규칙 추가] 클릭.
     * 포트 범위: `3000`, 소스: `0.0.0.0/0` (또는 사내 IP 대역 지정), 유형: `사용자 지정 TCP` 추가 및 저장.
   
   - **리눅스 서버 환경 (UFW / Firewalld)**:
     * Ubuntu (UFW):
       $ sudo ufw allow 3000/tcp
       $ sudo ufw reload
     * CentOS / RHEL (Firewalld):
       $ sudo firewall-cmd --permanent --add-port=3000/tcp
       $ sudo firewall-cmd --reload
   
   - **Windows Server 환경 (고급 보안이 포함된 Windows 방화벽)**:
     * 시작 -> '고급 보안이 포함된 Windows 방화벽' 실행 -> '인바운드 규칙' 마우스 우클릭 -> '새 규칙'.
     * 규칙 종류: `포트` -> 프로토콜 및 포트: `TCP / 특정 로컬 포트: 3000`.
     * 작업: `연결 허용` -> 프로필: 전부 체크 -> 이름: `PGuard Backend Server` 설정 후 마침.

4. Nginx 리버스 프록시 연계 및 SSL(HTTPS) 적용 조언 (고도화 권장):
   - 에이전트와 서버가 공용 인터넷망을 거쳐 패킷을 송수신할 경우 보안을 위해 SSL 암호화 적용이 극히 권장됩니다.
   - 서버 전면에 Nginx 웹서버를 배치하고 `Certbot (Let's Encrypt)`를 사용하여 HTTPS를 설정한 뒤, 
     Nginx의 프록시 패스 설정을 통해 3000번 포트로 패킷을 포워딩해 주는 아키텍처가 이상적입니다.
     (예시 Nginx config):
     ```nginx
     server {
         listen 443 ssl;
         server_name pguard.yourcompany.com;
         ssl_certificate /etc/letsencrypt/live/pguard.yourcompany.com/fullchain.pem;
         ssl_certificate_key /etc/letsencrypt/live/pguard.yourcompany.com/privkey.pem;

         location / {
             proxy_pass http://localhost:3000;
             proxy_set_header Host $host;
             proxy_set_header X-Real-IP $remote_addr;
             proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
             proxy_set_header X-Forwarded-Proto $scheme;
         }
     }
     ```
