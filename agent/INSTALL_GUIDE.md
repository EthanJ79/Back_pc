# 🛡️ PGuardAgent 양대 OS(Windows & macOS) 설치 및 배포 매뉴얼

본 문서는 사내 직원 PC 활동 및 웹사이트 방문 수집 에이전트(`PGuardAgent`)를 **Windows**와 **macOS** 환경에서 최종 사용자가 마우스 더블클릭만으로 실행할 수 있도록 배포 패키지를 만들고 설치하는 종합 가이드입니다.

---

## ⚠️ [중요] macOS 패키징 빌드 가이드 (사전 지식)
> [!NOTE]
> PyInstaller나 py2app 등 OS 네이티브 컴파일러는 **해당 타겟 OS 환경에서 실행해야만** 실행 바이너리가 추출됩니다. (윈도우 컴퓨터에서 맥용 실행 파일을 직접 빌드할 수 없음)
> 따라서, macOS용 패키지(`.app` 또는 단일 실행 파일)를 빌드하려면 **사내 개발용 맥북이나 Mac PC에서 아래 과정을 단 한 번 수행**해야 합니다.

### 🍎 Mac 컴퓨터에서 macOS 에이전트 패키징 빌드 명령어
맥북 또는 Mac 환경에서 터미널을 열고 다음 과정을 진행하여 단일 실행 파일 및 앱(`.app`)을 빌드합니다:

1. **필수 라이브러리 및 PyInstaller 설치**:
   ```bash
   pip3 install requests psutil pyobjc-core pyobjc-framework-Cocoa pyobjc-framework-Quartz pyinstaller
   ```
2. **macOS용 독립 실행 파일 및 앱(.app) 빌드**:
   ```bash
   pyinstaller --onefile --noconsole --name="PGuardAgent" agent.py
   ```
   * 빌드가 완료되면 `dist` 폴더 안에 맥에서 즉시 더블클릭해 가동할 수 있는 **`PGuardAgent.app`** 및 단일 바이너리 파일이 생성됩니다.
   * 이 `PGuardAgent.app` 파일을 최종 Mac 사용자 직원들에게 배포하시면 됩니다.

---

## 🪟 1. Windows 사용자용 설치 및 가동 가이드

윈도우 사용자는 파이썬이나 라이브러리를 전혀 설치할 필요 없이, 사전 빌드된 단 하나의 실행 파일만으로 가동이 완료됩니다.

### 🚀 간편 설치 및 실행 단계
1. **에이전트 다운로드**:
   - 관리자가 공유해 준 배포 폴더 또는 이메일에서 **`PGuardAgent.exe`** 파일을 다운로드하여 원하는 로컬 디렉토리(예: `C:\Program Files\PGuardAgent` 등)에 배치합니다.
2. **실행**:
   - 다운로드한 **`PGuardAgent.exe`** 파일을 마우스로 **더블클릭**합니다.
   - 백그라운드 모드로 구동(`--noconsole`)되므로 겉으로는 아무런 창도 뜨지 않으나, 작업 관리자를 열어 보면 프로세스가 조용히 작동 중임을 확인할 수 있습니다.

### 🔄 PC 켤 때마다 자동으로 켜지게 설정 (시작프로그램 등록)
> [!TIP]
> **자동 등록 지원**: 에이전트(`PGuardAgent.exe` 또는 파이썬 스크립트)를 **최초 1회 실행하는 즉시**, 윈도우 레지스트리(`HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run`)에 자동으로 등록되어 다음 부팅부터 자동으로 백그라운드 구동됩니다. 따라서 별도의 수동 등록 과정은 생략하셔도 무방합니다.

1. (수동 등록 시) 단축키 `Win + R`을 누르고 실행 창에 `shell:startup`을 입력한 뒤 엔터를 누릅니다. (시작프로그램 폴더가 열립니다)
2. 다운로드해 둔 `PGuardAgent.exe` 파일의 **바로가기(Shortcut)**를 해당 폴더 안에 드래그 앤 드롭으로 추가합니다.
3. 이제 아침에 컴퓨터를 켤 때마다 자동으로 모니터링이 안전하게 시작됩니다.

### 🛑 작동 강제 중지 및 삭제 방법
- 단축키 `Ctrl + Shift + Esc`를 눌러 **작업 관리자**를 켭니다.
- 프로세스 목록에서 **`PGuardAgent.exe`**를 찾아 우클릭한 후 **`작업 끝내기`**를 누릅니다.
- 시작프로그램 폴더에 넣어둔 바로가기와 본체 exe 파일을 삭제하면 깨끗이 제거됩니다.

## 🍏 2. macOS 사용자용 설치 및 가동 가이드

맥(macOS)은 보안 정책이 윈도우보다 상대적으로 엄격하므로, 배포된 파일 실행 및 화면 윈도우 정보를 가져오기 위해 **보안 승인 설정**이 한 차례 요구됩니다.

### 🚀 간편 설치 및 실행 단계
1. **에이전트 다운로드 및 애플리케이션 등록**:
   - 관리자로부터 배포받은 **`PGuardAgent.app`**(또는 컴파일된 실행 파일)을 Mac의 **[응용 프로그램 (Applications)]** 폴더로 드래그하여 이동시킵니다.
2. **보안 차단 해제 및 실행 (최초 1회)**:
   - Mac 보안 정책상 앱스토어 외 승인되지 않은 앱 실행 시 차단 팝업이 뜰 수 있습니다.
   - 이 경우, 앱 아이콘을 우클릭(또는 두 손가락 탭)하여 **[열기]**를 선택한 후, 경고 팝업에서 **[열기]** 버튼을 다시 한번 눌러 신뢰를 승인해 줍니다.
3. **[필수] 시스템 권한 부여 (화면 활성 창 인식 목적)**:
   - 전면 활성화된 창 타이틀과 프로세스(예: 브라우저 도메인 분석)를 정확히 얻기 위해서는 Mac 고유의 접근성(Accessibility) 및 화면 기록(Screen Recording) 권한이 필요할 수 있습니다.
   - 권한 요청 알림이 뜨면 **[시스템 설정 열기]**를 클릭합니다.
   - **[개인정보 보호 및 보안] ➡️ [접근성]** 메뉴에서 `PGuardAgent` 스위치를 **켬(ON)**으로 활성화합니다.

### 🔄 PC 켤 때마다 자동으로 켜지게 설정 (로그인 항목 등록)
> [!TIP]
> **자동 등록 지원**: 에이전트(`PGuardAgent.app` 또는 파이썬 스크립트)를 **최초 1회 실행하는 즉시**, macOS LaunchAgent(`~/Library/LaunchAgents/com.pguard.agent.plist`)로 자동 등록되어 부팅 시 백그라운드 데몬으로 자동 실행 및 유지 관리(KeepAlive)됩니다. 따라서 별도의 수동 등록 과정은 생략하셔도 무방합니다.

1. (수동 등록 시) Mac 화면 좌측 상단의 (애플 로고)를 누르고 **[시스템 설정...]**으로 들어갑니다.
2. **[일반] ➡️ [로그인 항목 및 확장 프로그램]** 메뉴를 선택합니다.
3. **로그인할 때 열기** 목록 아래에 있는 **`+` (더하기)** 버튼을 누릅니다.
4. **[응용 프로그램]** 폴더의 **`PGuardAgent.app`**을 선택하여 등록해 줍니다.

### 🛑 작동 강제 중지 및 삭제 방법
- 단축키 `Cmd + Space`로 스포트라이트를 켜고 **활성 상태 보기 (Activity Monitor)**를 실행합니다.
- 검색창에 `PGuard`를 검색하고 프로세스를 선택한 후, 상단의 **`X` (강제 종료)** 아이콘을 클릭합니다.
- 응용 프로그램 폴더의 앱을 휴지통에 버리면 완전히 삭제됩니다.
